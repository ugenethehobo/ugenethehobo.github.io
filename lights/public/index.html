Install the hub software

  1. Use Chrome or Edge on a computer (Safari and iPhone can’t do this step).
  2. Plug the ESP32 board into the computer with a USB data cable.
  3. Click the button below and pick the board’s port (often “CP210x” or “USB Serial”). For a first install, choose to erase the device.

This browser can’t install it. Open this page in Chrome or Edge on a computer. Open this page over https to install.

No port shown? Install the board’s USB driver (CP210x or CH340), or hold the board’s BOOT button while clicking Connect.

Connect the hub

  1. Plug the hub into any USB charger near your lights.
  2. On your iPhone, open Settings → Wi-Fi and join Hue-Hub-…. A setup page opens.
  3. Tap Configure WiFi, pick your home Wi-Fi (2.4 GHz), type its password, and enter the server address . Save.
  4. In the Lights app, approve the new hub. Then tap + to add lights.

The hub’s light: slow blink = connecting, double blink = waiting for approval, steady = ready. Hold BOOT for 5 seconds to start setup again.
